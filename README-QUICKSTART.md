# TabMover v0.3.0-alpha quick start

This package is a development alpha. It is not yet capable of transferring tabs or sessions.

CI artifacts:
- `TabMover-Setup-v0.3.0-alpha.exe` — Windows installer.
- `TabMover-portable-windows-x64.zip` — portable desktop shell.

Browser integration folders are prototypes and are not store-published extensions. Do not install them into a profile containing important authenticated sessions until implementation and security review are complete.
