# Roadmap

## 0.3.0-alpha — current
Desktop settings shell, installer/portable definitions, browser integration prototypes, session-transfer security model. No end-to-end transfer yet.

## 0.3.1-alpha
Native messaging host, local IPC broker, browser connection health, permission onboarding, drag state machine, visible drop overlay.

## 0.3.2-alpha
Single-tab URL transfer; cookie and origin-storage capture/restore prototypes; structured transfer receipts.

## 0.3.3-alpha
Destination verification, configurable source closure, failure recovery, redacted diagnostics.

## 0.4.0-beta
Brave ↔ Opera hardening, Chromium and Firefox compatibility, DPI/multi-monitor/browser-update edge cases.

## 1.0.0
Signed installer and published browser integrations, security review, compatibility matrix.
