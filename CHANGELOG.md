# Changelog

## 0.3.0-alpha
- Reframed TabMover as a desktop-first Windows application with background browser integrations.
- Added configurable source-tab closure policy and session-data settings.
- Added desktop settings shell with transfer, session, browser, and privacy tabs.
- Added Chromium and Firefox WebExtension integration prototypes.
- Added Inno Setup installer definition.
- Added CI packaging for portable and installer distributions.
- Added architecture, security, product, roadmap, and test documentation.

### Not implemented in this alpha
- End-to-end native drag broker and desktop-to-extension relay.
- Complete cookie/storage capture and restoration orchestration.
- Destination verification and safe source-tab closure.
- Signed browser-store extension packages.
